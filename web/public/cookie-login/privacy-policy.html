cookie login Privacy Policy

Effective date: August 16, 2026

cookie login helps users transfer website session data between Chrome and compatible multi-profile browsers by importing and exporting user-selected JSON files.

Data handled

When the user explicitly starts an import or export, cookie login may handle:

  • Authentication information, including website Cookies.
  • Web history information limited to the current website URL, domain, and the website origins included in a user-selected import file.
  • Website content stored in localStorage for the relevant website origins.

How the data is used

This data is used only to provide the extension's single purpose: importing and exporting website session data at the user's direction.

Storage and retention

cookie login does not send session data to a developer-operated server. Exported data is saved as a local JSON file chosen by the user. Imported data is read from a local JSON file selected by the user and is written to the relevant browser Cookie and localStorage areas. The developer does not retain this data.

Sharing

cookie login does not sell user data or transfer it to third parties. The extension does not use user data for advertising, creditworthiness, lending, analytics, or purposes unrelated to session import and export.

User control

The extension processes session data only after the user chooses Import or Export. Users can delete exported JSON files at any time and can remove imported Cookies or localStorage through their browser or the relevant website.

Security

Session export files may contain sensitive authentication data. Users should store them securely, share them only with trusted destinations, and delete them when they are no longer needed.

Limited Use

Use of information by cookie login follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

Changes

This policy will be updated if the extension's data practices change. The effective date above identifies the current version.
